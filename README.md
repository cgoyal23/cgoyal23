## Selected projects

### [FINN — Financial Investment Agent](https://github.com/cgoyal23/finn-investment-agent) · [Live demo](https://finn-investment-agent.vercel.app)
A full-stack investment research desk built with React, TypeScript, and Next.js. It combines historical market data with source-linked company research and an evidence-grounded Gemini workflow. The project documents data freshness, source coverage, and product limitations.

### [Competitive Graph Programming](https://github.com/cgoyal23/Competitive-graph-programming)
A C++17 graph-algorithm library with strongly connected components, minimum spanning trees, and shortest-path algorithms. Includes a header-only API, CMake build, and tests.

### [SE-DeblurGAN](https://github.com/cgoyal23/SE-DeblurGAN)
A PyTorch image-restoration experiment combining a U-Net generator, squeeze-and-excitation attention, and a hybrid training objective. The saved CelebA-subset notebook evaluation reports a 6.80 dB PSNR gain; the README documents reproducibility limits.
