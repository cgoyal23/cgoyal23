I'm interested in building useful software and understanding how it works under the hood. My projects explore full-stack development, concurrent systems, algorithms, and applied machine learning.

## Featured projects

🚀 **[FINN — Financial Investment Agent](https://github.com/cgoyal23/finn-investment-agent)** · [Live demo](https://finn-investment-agent.vercel.app)  
A full-stack investment research prototype using Next.js, React, and TypeScript. It combines market data, source-linked company research, and a Gemini-powered workflow, with documented data and product limitations.

🚕 **[RideFlow](https://github.com/cgoyal23/RideFlow)**  
A C++17 ride-hailing simulation exploring thread-safe driver matching, trip lifecycles, design patterns, and asynchronous notifications. Includes a console demo and automated tests.

⚙️ **[NFS Goes Online](https://github.com/cgoyal23/NFS-Goes-Online)**  
An educational systems prototype featuring an asynchronous Rust HTTP server, a VSFS-style filesystem, and a concurrent C UDP file server. The repository documents its scope and limitations.

🧩 **[Competitive Graph Programming](https://github.com/cgoyal23/Competitive-graph-programming)**  
A C++17 graph algorithms library covering strongly connected components, minimum spanning trees, and shortest paths, with a header-only API and tests.

🔬 **[SE-DeblurGAN](https://github.com/cgoyal23/SE-DeblurGAN)**  
A PyTorch image-restoration experiment using a U-Net generator and squeeze-and-excitation attention. The repository describes the evaluation and reproducibility limits.
